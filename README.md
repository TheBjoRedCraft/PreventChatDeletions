## Prevent Chat Deletions Mod


![image](src/main/resources/assets/prevent-chat-deletions/icon.png)

Prevents the server from deleting signed chat messages without breaking the players chat validation to work on servers with secure chat enabled. This does not handle server clearing your chat by spamming empty lines


_Mod icon inspired by [No Chat Restrictions](https://modrinth.com/project/z440MEwJ)_
